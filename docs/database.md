# Database Design

## Current setup

The application uses MySQL. The database connection is configured in
`backend/src/main/resources/application.properties`. The backend reads the
following environment variables, with local defaults shown in the properties
file:

| Variable | Default | Purpose |
|---|---|---|
| `DB_HOST` | `localhost` | MySQL server host |
| `DB_PORT` | `3306` | MySQL server port |
| `DB_NAME` | `student_task_manager` | Database name |
| `DB_USERNAME` | `root` | MySQL username |
| `DB_PASSWORD` | Empty | MySQL password |

Create the database before starting the backend. Hibernate is configured with
`spring.jpa.hibernate.ddl-auto=update`; it creates or updates the entity table
inside that database when the application starts. This is the project's local
development schema setup. There is no `schema.sql`, seed script, or migration
tool configured, and Hibernate does not create the database itself.

```sql
CREATE DATABASE student_task_manager
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;
```

The application does not insert sample rows automatically. Tasks are created
through the REST API or the frontend.

## Current entity: `tasks`

The `Task` JPA entity in
`backend/src/main/java/com/example/studenttaskmanager/model/entity/Task.java`
maps to a single `tasks` table. Hibernate derives the physical table and column
types from this entity and the configured MySQL dialect. The table below
describes the entity mapping, rather than promising exact database DDL.

| Entity field | Database column | Mapping and behavior |
|---|---|---|
| `id` | `id` | `BIGINT` primary key generated by the database |
| `title` | `title` | Required string, maximum 100 characters |
| `description` | `description` | Optional `TEXT` |
| `dueDate` | `due_date` | Optional `LocalDateTime` |
| `priority` | `priority` | Required enum stored by its name; defaults to `MEDIUM` in Java |
| `status` | `status` | Required enum stored by its name; defaults to `PENDING` in Java |
| `taskType` | `task_type` | Required enum stored by its name; defaults to `ASSIGNMENT` in Java |
| `createdAt` | `created_at` | Required `LocalDateTime`, set by the entity before insert |
| `updatedAt` | `updated_at` | Required `LocalDateTime`, set on insert and update by the entity |

The entity declares indexes for `status`, `task_type`, `due_date`, and
`priority`. Their names are `idx_tasks_status`, `idx_tasks_task_type`,
`idx_tasks_due_date`, and `idx_tasks_priority`.

## Data relationships

The current Phase 1 model has only the `Task` entity and no foreign-key
relationships. Course/subject organization and its proposed `courses` table
are future work; no such table or relationship is currently created by the
application.

## Schema changes

For local development, `ddl-auto=update` lets Hibernate align the database
with the current entity mapping. This is not a versioned migration strategy.
For production or shared environments, a migration tool and reviewed schema
migrations should be introduced before relying on automatic schema updates.
